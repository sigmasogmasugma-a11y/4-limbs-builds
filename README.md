# 4 Limbs — test builds

Four players, one body, one coat: each of you controls one limb of four kids stacked in
a trenchcoat, trying to pass as one normal person while you pull off a heist.

**[Download the latest build](https://github.com/sigmasogmasugma-a11y/4-limbs-builds/releases/latest)**
(Windows and Mac, on the same page).

These are early test builds. Only the builds live here, not the game's code.

## Windows

1. Download `4Limbs-Windows.zip` and unzip it (right-click > Extract All).
2. Open the `4Limbs-Windows` folder and run `4Limbs.exe`.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
   Allow it through the firewall if asked, so online play works.

## Mac

1. Download `4Limbs-macOS.zip` and double-click it. You get `MultiPlayer.app`.
2. The app isn't signed by Apple, so the first time macOS blocks it: right-click the app,
   choose **Open**, then **Open** again.
3. If it says the app "is damaged" or still won't open, run this once in Terminal, then
   open it again:
   ```
   xattr -cr ~/Downloads/MultiPlayer.app
   ```

## Playing online together

- Everyone needs the **same build** (the newest one here).
- On the **Play** page, check that everyone's **Server** button shows the same region.
- Host: **Create Lobby** and send the 4-letter code. Friends: type the code, **Join Lobby**.
- Everyone plays on W A S D (move), E (grab, or crouch for a leg) and Q (in and out of the
  coat). With two or three players your second limb is on I J K L, O and U.
- Voice chat is on: friends are louder the closer they are. V turns your mic off.

## Playing on one keyboard

All four share one keyboard: left leg W A S D / E / Q, right leg I J K L / O / U,
left arm T F G H / R / B, right arm `[ ; ' \` / Right Shift / M.
